# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for a security problem. That publishes it before there is a fix.

Instead, report it privately through GitHub: open the **Security** tab of this repository and choose
**Report a vulnerability**, or go straight to
<https://github.com/kaymyg/ames/security/advisories/new>.

Please include:

- what is affected and how,
- a minimal way to reproduce it,
- the commit or version you tested.

## What to expect

AMES is an independent research project, so responses are best effort rather than on a fixed schedule.
Valid reports will be acknowledged, fixed as soon as practical, and credited (with your permission).
